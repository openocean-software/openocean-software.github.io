## Overview

ros_acomms is a ROS package that provides a generic ROS interface to the WHOI Micromodem and transparent transport of ROS messages across an acoustic link. It also provides simulation capabilities.

The same packages build under ROS 1 (catkin) and ROS 2 (ament). Source is on the [WHOI GitLab](https://git.whoi.edu/acomms/ros_acomms), and the [documentation](https://acomms.pages.whoi.edu/ros_acomms) covers setup and the simulator.

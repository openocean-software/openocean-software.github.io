    Toolkit

    The build pipeline, the signed apt repository and the public plan. All of it is open source under the openocean-software GitHub organization.

    Packages

    Member projects keep a working build (CMake, pyproject.toml, etc.) and a tagged release schedule. The openocean-build pipeline builds, signs, and publishes the packages to apt.oceansoft.org.

    git, a working build, tagged releases

    Open Ocean pipeline

    sbuild in Docker, Debian packaging, GPG signing

    Install from apt.oceansoft.org

    Trust

    These instructions assume oceansoft.org hasn't been compromised (and thus lists the correct GPG fingerprint: OOS_KEY). This is normally a safe assumption, but if your security requirements call for it, consider independently verifying our signing key, e.g. using Keybase or other out-of-band techniques.

    For Debian stable/oldstable and Ubuntu active LTS releases:

    • Get the signing key (details): 
      OOS_KEY=D7D7224D53A4F29E303FE01DEB505B68A5D063B0
OOS_KEYRING=/etc/apt/keyrings/oceansoft.gpg
gpg --keyserver keyserver.ubuntu.com --recv-keys $OOS_KEY && gpg --export $OOS_KEY | sudo tee $OOS_KEYRING > /dev/null
    • Add apt sources: 
      DISTRO=$(. /etc/os-release; echo "$ID")             # "ubuntu" or "debian"
DIST=$(. /etc/os-release; echo "$VERSION_CODENAME") # e.g., "resolute"
REPO=http://apt.oceansoft.org/$DISTRO-$DIST/
echo "deb [signed-by=$OOS_KEYRING] $REPO $DIST main" | sudo tee /etc/apt/sources.list.d/oceansoft.list
sudo apt update

    • Install packages: 

      apt install ...

    • Full list of packages available: 

      apt install lz4
lz4cat /var/lib/apt/lists/apt.oceansoft.org*_Packages.lz4

    Roadmap

    The plan is public in openocean-plan. The technical goals come from 114 interviews with people in academia, industry and government, described in the AUV26 paper. Comment on any of them on the forum.

    Goal Status What it gives member projects
    Middleware interoperability In progress Common message set and maintained bridges
    Linux packages In progress Shared, signed apt repository
    Continuous integration Planned Shared CI templates and maturity badges
    Embedded builds Planned Raspberry Pi and ARM builds in CI
    Docker images Planned Dockerfile templates and multi-arch images
    Data QA/QC and FAIR data Planned QC checklists, metadata templates, provenance
    Open Ocean Software

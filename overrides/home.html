What membership brings

Open Ocean Software is a shared crew. Projects keep their own code and roadmap; we provide the services no single lab has time to run.

  1. Trust

    A secure build pipeline, GPG-signed packages, and OpenSSF Scorecard tracking for member repositories.

  2. Discoverability

    One directory, one forum, and project manifests, so users find the right tool and the right people.

  3. Interoperability

    Common messages and maintained bridges across ROS 2, MOOS-IvP, Goby, and LCM.

  4. Accessibility

    DevOps help and binary packages, so new users install with apt instead of building from source.
